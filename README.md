# AUTO ESCRITOR
🎈AUTOMATIZE O PROCESSO DE DIGITAÇÃO.

<img src="FOTO.png" align="center" width="500"> <br>

## DESCRIÇÃO:
O aplicativo **"AUTO ESCRITOR"** é uma ferramenta desenvolvida em **Python** com interface gráfica utilizando **Tkinter**, projetada para **automatizar a digitação de textos** em qualquer campo editável do ambiente de desktop. Ele é útil para tarefas repetitivas, testes ou automações simples que envolvem entrada de texto.

## FUNCIONALIDADES:
1. **Campo de Texto para Inserção:**

   * Área expansível onde o usuário pode digitar ou colar o texto que será digitado automaticamente.

2. **Controle de Velocidade de Digitação (segundos):**

   * Um controle deslizante ajusta a velocidade entre cada caractere digitado, variando de **0.010 a 0.100 segundos**.

3. **Controle de Atraso Inicial (segundos):**

   * Um controle deslizante permite configurar o tempo de espera antes do início da digitação, variando de **1 a 10 segundos**. Isso dá tempo para posicionar o cursor no local desejado.

4. **Validação de Campo:**

   * O aplicativo impede o início da automação ou a limpeza do campo se o campo de texto estiver vazio, exibindo alertas informativos.

5. **Botão "INICIAR":**

   * Ao clicar, a janela é minimizada, e a digitação começa após o atraso configurado. O texto é digitado com a velocidade definida.
   * Após concluir a digitação, uma mensagem de confirmação é exibida ao usuário: **"A digitação foi concluída com sucesso!"**

6. **Botão "LIMPAR":**

   * Remove todo o conteúdo do campo de texto. Caso o campo já esteja vazio, exibe uma mensagem informando isso ao usuário.

7. **Interface Amigável:**

   * Design simples, funcional e com janela inicializada em tela cheia para facilitar a visualização dos controles.

## EXECUTANDO O PROJETO:
1. Acesse o diretório onde está o código, por exemplo `./CODIGO`, e execute o script principal:

   ```bash
   python CODIGO.py
   ```

2. A interface gráfica será aberta automaticamente.

3. No campo de texto, digite ou cole o conteúdo que deseja automatizar.

4. Ajuste a **velocidade de digitação** usando o controle deslizante (quanto menor o valor, mais rápida será a digitação).

5. Defina o **tempo de atraso inicial** para posicionar o cursor no local desejado antes do início.

6. Clique no botão **"INICIAR"**:

   * A janela será minimizada.
   * Após o tempo de espera, o texto será digitado automaticamente com os intervalos definidos.

7. Ao final da digitação, uma janela de mensagem informará que o processo foi concluído.

8. Para limpar o texto e reutilizar o aplicativo, clique em **"LIMPAR"**.

9. Para sair, basta fechar a janela normalmente.
